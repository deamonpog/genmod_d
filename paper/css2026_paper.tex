\begin{abstract}
Agent-based modelers have worried for decades that different behavioral rules can
generate indistinguishable macroscopic patterns. Equifinality is usually stated as a
caveat. We show it can be \emph{measured}.

We recast inverse generative social science as classification over a library of
candidate rules, and attach conformal prediction to the classifier. Conformal
prediction returns a \emph{set} of rules guaranteed to contain the true generator
with probability at least $1-\alpha$, without distributional assumptions and
regardless of how good the classifier is. The size of that set is therefore a
calibrated, observation-conditional measure of equifinality: when the data cannot
separate three mechanisms, the set contains three rules, and the guarantee certifies
that this is a fact about the data rather than a failure of the analyst.

We demonstrate this in three settings. In \textbf{Schelling segregation}, a library
of 2,089 behaviorally distinct utility rules is narrowed to 53 candidates at
$90\%$ confidence -- a 40-fold reduction, with a guarantee. In \textbf{collective
motion}, five agents move under one of eleven known neighbor-selection rules: from
\SI{7}{\second} of trajectory the $95\%$ set contains 3.3 of the eleven rules and
only $1.4\%$ of observations resolve the mechanism uniquely; from \SI{28}{\second} it
contains 1.2 rules and $79\%$ resolve. Equifinality is not a fixed property of a rule
library. It is a property of the library \emph{and the observation}, and it decays
measurably as observation accumulates.

Identifiability is governed by \textbf{what a model can represent}, not by
\textbf{how large it is}: a 156k-parameter recurrent network over group averages
matches a 1.8M-parameter transformer over per-agent trajectories (paired difference
$-0.002$, $95\%$ CI $[-0.008,+0.005]$), while changing how spatial position is
\emph{encoded}, at constant capacity, inflates the segregation prediction sets by
$68\%$.

Finally we transfer the simulation-trained library onto \textbf{physical robots}
programmed with the same rules. It largely fails ($0.375$), and the reason matters:
robots executing a given rule school $1.7\times$ less tightly than simulated agents
executing it, so the classifier reads their behavior correctly and infers the wrong
rule. Rule identification recovers the \emph{effective} rule of the substrate the
library was built on, not the \emph{programmed} one. Transporting the conformal
calibration across this shift fails silently -- $47\%$ coverage while promising
$95\%$ -- whereas recalibrating on a handful of robot runs restores validity and
returns sets containing 10 of 11 rules: the framework correctly reporting that it
cannot identify the mechanism. \textbf{Conformal prediction guarantees honesty, not
competence.}
\end{abstract}

\section{Introduction}

Epstein's generative dictum -- ``if you didn't grow it, you didn't explain it'' --
licenses a model by its ability to produce a target pattern. The inverse question is
harder and more useful: given the pattern, \emph{which rule grew it?} Inverse
generative social science (IGSS) asks exactly this, and typically answers by search
-- evolving candidate rules and keeping those whose output resembles the target
\citep{gunaratne2020,gunaratne2023,epstein2023}.

Two problems dog this program. The first is cost. The second, and deeper, is
\textbf{equifinality}: several distinct rules may generate output that no observer
can tell apart \citep{beven2006}. A search returns a rule; it does not say how many
\emph{other} rules would have served equally well. Modelers know this and hedge, but
the hedge is rhetorical. There is no number.

This paper supplies one. We recast rule recovery as supervised classification over a
library of candidate rules, then wrap the classifier in \textbf{conformal
prediction} \citep{vovk2005,angelopoulos2021}, which converts scores into a set
$C(W)$ of candidate rules with a distribution-free guarantee
%
\begin{equation}
\Pr\bigl(g_{\text{true}} \in C(W)\bigr) \;\ge\; 1-\alpha ,
\label{eq:coverage}
\end{equation}
%
requiring only that calibration and test data be exchangeable. Crucially,
\emph{the guarantee holds whether or not the classifier is any good.} A weak
classifier does not break the coverage; it simply returns larger sets.

That is what makes set size meaningful. Because coverage is guaranteed, $|C(W)|$
cannot be waved away as a modeling artifact: it is a calibrated statement about how
much the \emph{observation} constrains the \emph{rule}. A singleton means the
mechanism is identified. A set of three means three mechanisms remain live at the
requested confidence. \textbf{Equifinality, quantified, conditional on the data you
actually have.}

\paragraph{Contributions.}
\begin{enumerate}
\itemsep2pt
\item \textbf{Conformal sets as an equifinality measure} for ABM rule recovery, with
a coverage guarantee that makes set size interpretable rather than incidental.
\item \textbf{Demonstration across two simulated domains} -- 2,089 rules on a
lattice, 11 rules in continuous space -- with nominal coverage in both, and a
measurement of how equifinality \emph{decays} with observation length.
\item \textbf{An information ladder}: which \emph{observations} make a rule
identifiable (relational structure, then temporal structure), and the finding that
beyond these, model capacity contributes nothing measurable.
\item \textbf{A transfer to physical robots} that locates the framework's limit:
rule identification recovers the \emph{effective} rule of its training substrate,
and the conformal layer -- properly recalibrated -- reports that failure honestly
instead of guessing confidently.
\end{enumerate}

\section{Background}

\paragraph{Inverse generative social science.}
Evolutionary model discovery \citep{gunaratne2020} evolves rule trees and uses
random-forest importance to rank influential factors; \citet{gunaratne2023} apply it
to residential segregation. The output is a rule and a factor ranking, not a
calibrated set of alternatives.

\paragraph{Equifinality and pattern-oriented modeling.}
That many structures reproduce a pattern is a familiar hazard \citep{beven2006}. The
standard response is pattern-oriented modeling \citep{grimm2005}: constrain the model
with \emph{multiple} patterns, on the reasoning that a rule surviving several filters
is more likely correct. This is sound but informal -- \emph{which} patterns, and how
much constraint does each buy? Section~\ref{sec:ladder} answers that empirically;
Section~\ref{sec:equifinality} turns the residual ambiguity into a number.

\paragraph{Calibration and summary statistics.}
ABM calibration, including approximate Bayesian computation, turns on the choice of
summary statistics: statistics that discard the information distinguishing two
mechanisms render those mechanisms inferentially identical. Our information ladder
measures this directly.

\paragraph{Conformal prediction.}
Split conformal \citep{vovk2005} uses a held-out calibration set to convert scores
into sets with finite-sample coverage. RAPS \citep{angelopoulos2021} is an adaptive
variant penalizing long tails. We use RAPS throughout.

\section{Framework}

The pipeline is domain-agnostic and has four stages.

\begin{enumerate}
\itemsep2pt
\item \textbf{Rule library.} Enumerate or generate a set $\mathcal{G}$ of candidate
behavioral rules, and deduplicate them \emph{behaviorally} -- two rules that produce
indistinguishable dynamics are one rule, and keeping both would manufacture ambiguity
rather than measure it.
\item \textbf{Forward simulation.} Run each rule to produce labelled observations.
\item \textbf{Recovery.} Train a classifier $P(g \mid W)$ mapping an observation
window $W$ to a distribution over rules.
\item \textbf{Conformal layer.} On a held-out calibration partition never used for
training or model selection, calibrate RAPS to produce $C(W)$ satisfying
Equation~\ref{eq:coverage}.
\end{enumerate}

\paragraph{The experimental unit is the simulation run, never the observation
window.} Windows from the same run are dependent; treating them as independent
inflates apparent performance and silently voids the conformal guarantee, which needs
calibration and test scores to be exchangeable. Throughout, whole runs are assigned
to partitions, evaluation windows within a run do not overlap, and all confidence
intervals bootstrap over runs.

\section{Case study 1: Schelling segregation (2,089 rules)}
\label{sec:schelling}

\paragraph{Rules.}
In Schelling's model \citep{schelling1971} an agent relocates when dissatisfied with
its neighborhood; what makes it a rule-recovery problem is that the utility function
driving that decision is not observed. Following \citet{gunaratne2023}, we take that
utility to be an arithmetic expression tree over six primitive factors -- same-type fraction, neighbor tenure,
distance from home, vacancy fraction, recent moves, and neighbor utility -- combined
with $+\,-\,\times\,\div$. From 10,000 generated candidates (depth $\le 3$),
behavioral deduplication against fixed probe simulations retains \textbf{2,089
behaviorally distinct trees}, which become the class labels.

\paragraph{Observations.}
A $50\times50$ torus, density $0.95$, Moore neighborhood, 500 ticks, with snapshots
at ticks 100--500. Each snapshot is tokenized into $2\times2$ patches; a transformer
encoder (3.9M parameters) with decomposed time/space embeddings classifies the
sequence. Each tree is simulated 100 times, giving ${\sim}209$k labelled sequences
split 80/10/10 by run.

\paragraph{Results.}
Chance top-1 is $1/2089 = 0.048\%$. The classifier reaches top-1 $0.319$ ($665\times$
chance), top-3 $0.485$, top-5 $0.562$, with pre-temperature ECE $0.017$: it extracts
a strong signal about the generating rule from five grid snapshots, and its raw
softmax is already well calibrated.

2,089 candidate rules are narrowed to 53: a 40-fold reduction, with a guarantee.}}
\label{tab:schelling-conformal}
\begin{tabular}{lccc}
\toprule
$\alpha$ & target & empirical coverage & mean $|C|$ (\% of library) \\
\midrule
0.01 & 0.99 & 0.989 & 234.3 \; (11.2\%) \\

Coverage tracks the nominal level at every $\alpha$ (Table~\ref{tab:schelling-conformal}).
In absolute terms the sets are large -- but the right denominator is the library. This
is a quantitative statement about how much a five-snapshot observation of a
segregation process constrains the underlying utility rule, and it is the kind of
statement the IGSS literature has not previously been able to make. The remaining
ambiguity is not noise but structure: the surviving rules are behaviorally similar
trees.

\subsection{Representation matters, at constant capacity}
\label{sec:rowcol}

We ablate one thing: how spatial position is encoded. The base model learns a
separate embedding for each of the 625 patch positions; the ablation decomposes it
into a learned row vector plus a learned column vector. This \emph{reduces} parameters
slightly (3.73M vs 3.88M) and leaves the observation, the data, and the training
budget untouched. Only the model's representational form changes.

\begin{table}[t]
\centering
\small
\caption{Spatial-embedding ablation. Accuracy barely moves; the conformal sets
inflate by $68\%$. A model can be equally \emph{right} and considerably less
\emph{informative}.}
\label{tab:rowcol}
\begin{tabular}{lccc}
\toprule
 & top-1 & mean $|C|$ @ $\alpha{=}0.10$ & @ $\alpha{=}0.05$ \\
\midrule
flat spatial embedding      & \textbf{0.319} & \textbf{52.9} & \textbf{104.2} \\
decomposed row $+$ column   & 0.312 & 88.7 & 192.4 \\
\bottomrule
\end{tabular}
\end{table}

Accuracy is nearly unchanged ($0.319$ vs $0.312$), but the row/column model needs 89
candidate rules where the flat model needs 53 to make the same coverage guarantee.
This matters twice. First, \textbf{set size is a more discriminating diagnostic than
accuracy} -- a difference invisible in top-1 is stark in the equifinality measure.
Second, read against Section~\ref{sec:ladder}, it locates precisely what does and
does not matter: there, an eleven-fold increase in \emph{capacity} buys nothing; here,
a change in \emph{representation} at constant capacity costs $68\%$ of the resolving
power.

\section{Case study 2: collective motion (11 rules)}
\label{sec:fish}

The segregation study leaves an objection: perhaps the classifier recognizes
\emph{grid textures}, not behavioral rules. So we move to a domain with no grid, no
lattice, and a rule space small enough to be exhaustively understood.

\subsection{The benchmark}

Five agents move in a circular arena ($R = \SI{0.25}{\metre}$) under burst-and-coast
dynamics. A rule $g=(s,k)$ fixes a neighbor-selection strategy $s$ and the number $k$
of neighbors attended to: no interaction ($k{=}0$); the $k$ \textbf{nearest}, $k$
\textbf{random}, or $k$ \textbf{most influential} neighbors for $k \in \{1,2,3\}$; or
\textbf{all} four. Eleven rules; chance $0.091$.

The families differ \emph{only} in which neighbors enter the social sum -- the
interaction functions are identical. This makes the benchmark sharp, and it makes the
high-$k$ rules genuinely hard: with $k=3$ of 4 available neighbors, ``nearest three'',
``random three'' and ``most influential three'' draw from nearly the same pool.

We use the \textbf{simulated-agent} trajectories released with \citet{lei2020}, who
build on the burst-and-coast model of \citet{calovi2018}. These are model output, not
empirical fish data, and the point is precisely that: the generating rule is known for
every run. Eleven rules $\times$ 50 runs $=$ 550 runs, balanced. Time is irregular
\textbf{kick time} (median interval \SI{0.434}{\second}), so we index sequences by
kick event rather than resampled clock time -- interpolating onto a uniform grid would
smooth away the discontinuities through which the rule acts.

\subsection{A leakage hazard worth documenting}

Experiment identifiers are \textbf{shared across the eleven rule files}, and runs
begin from common initial placements: inspecting the first recorded event of every
run, one experiment is identical across all eleven rules and thirteen more are
partially identical. A classifier could learn the \emph{initial condition} rather than
the rule.

We block this twice: the grouping key is the experiment id applied across all eleven
rules at once (if experiment 42 is in test, all eleven of its runs are), and we
discard a 50-event burn-in that removes both the placement transient and the region
where the coupling lives. Grouped 5-fold cross-validation over the 50 seeds; each
experiment is tested exactly once. We report this because it is the kind of hazard
that inflates results silently, and because it is a property of a widely-used public
dataset.

\subsection{The information ladder}
\label{sec:ladder}

We compare four \textbf{observation designs}, holding the task fixed, at $T=64$ kicks
(\SI{28}{\second}); see Figure~\ref{fig:ladder} and Table~\ref{tab:ladder}.

\begin{table}[t]

\begin{figure}[t]
\centering
\includegraphics[width=0.86\textwidth]{fig1_ladder.pdf}
\caption{Identifiability is set by what the model observes, not by how it is built.
Relational information is worth $+0.365$; the time course a further $+0.212$; an
eleven-fold increase in capacity, nothing.}
\label{fig:ladder}
\end{figure}

\textbf{Relational information is worth $+0.365$.} An observer recording only how
each fish moves -- speed, turning, wall distance -- recovers the rule $35\%$ of the
time. Letting it see the neighbors doubles that.

\textbf{Temporal information is worth $+0.212$.} The \emph{identical} relational
statistics, fed to a model that sees their time course rather than their window
average, go from $0.717$ to $0.929$. The rules differ in the \emph{persistence} of the
influencing set, and a window average cannot express persistence.

\textbf{Capacity is worth nothing.} A 156k-parameter GRU over thirteen group averages
matches a 1.8M-parameter transformer over per-agent trajectories: paired difference
$-0.0015$, $95\%$ CI $[-0.008,+0.005]$, bootstrapped over runs.

\paragraph{A methodological caution, since it nearly misled us.}
Our first transformer, trained for 40 epochs, scored $0.825$ and appeared to lose to
the GRU by ten points. Its validation accuracy was still climbing when the epoch
budget ran out; early stopping never fired. At 120 epochs the same architecture
reaches $0.927$. \textbf{A negative result about architecture is worthless unless
every model is trained to convergence}, and the failure mode is silent -- an
undertrained model returns a perfectly plausible number, and a comparison against it
will confidently support the wrong conclusion.

That is also where conformal prediction earns its keep.

\label{sec:equifinality}

\textbf{At seven seconds of observation, the average $95\%$-confidence prediction set
contains 3.28 of the eleven rules, and only $1.4\%$ of observations resolve the
mechanism to a single rule. By twenty-eight seconds the set holds 1.22 rules and
$79\%$ resolve.} Equifinality is therefore \textbf{not a fixed property of a rule
library}. It is a property of the library \emph{and the observation}, and it decays
measurably as observation accumulates. That is the quantity this paper proposes to
report.

\paragraph{The over-coverage at long windows is a ceiling effect, and it is
instructive.} With top-1 accuracy at $0.93$ and a convention of never returning an
empty set, coverage cannot fall below ${\sim}0.93$ whatever $\alpha$ requests; the
sets have collapsed to singletons and there is nothing left to express.
\emph{Measuring equifinality at an observation length where the task is already solved
measures nothing.} This is a caution for anyone tempted to calibrate on a saturated
model and conclude that a system exhibits no equifinality: they will have measured the
ceiling, not the system.

\subsection{The residual equifinality is structured}

We expected confusions to stay inside a strategy family and slip on $k$
(``nearest-2'' mistaken for ``nearest-3''). \textbf{The reverse is true.} The
transformer recovers the exact rule at $0.927$, the strategy family at $0.939$, and
the \emph{neighbor count} $k$ at $\mathbf{0.959}$. Of its errors, $43\%$ preserve the
correct $k$ while getting the family wrong; only $16\%$ do the opposite.

\textbf{How many neighbors an agent attends to is far easier to recover than which
neighbors it selects.} The mechanism explains it. $k$ sets the effective strength of
cohesion, written directly into group geometry -- mean nearest-neighbor distance falls
monotonically with $k$ within every family ($0.28$, $0.22$, $0.19$ for
nearest-1/2/3). \emph{Which} neighbors are chosen is a subtler, higher-order property,
and at $k=3$ of four available neighbors the three families draw from an almost
identical pool. They converge behaviorally. No observer -- and no amount of model
capacity -- can separate them.

\begin{figure}[t]
\centering
\includegraphics[width=0.62\textwidth]{fig4_confusion.pdf}
\caption{The errors are not scattered. They concentrate in a high-$k$ cluster --
nearest-3, random-3, influential-3 and all-4 -- where the selection rules draw from
nearly the same pool of neighbors and therefore converge behaviorally. No-interaction
is recovered perfectly.}
\label{fig:confusion}
\end{figure}

The confusion matrix (Figure~\ref{fig:confusion}) shows this directly: the errors
concentrate in the high-$k$ cluster, while no-interaction is recovered perfectly and
random-1 at $0.97$.

\textbf{This is where the conformal set pays off.} A prediction set
$C(W) = \{\text{nearest-3},\ \text{influential-3},\ \text{all-4}\}$ is not a
classifier failing. It is a calibrated, coverage-guaranteed statement that
\emph{three mechanisms are behaviorally indistinguishable given this observation}. The
equifinality is a property of the system and the data, not of the analyst's model
choice -- and the guarantee is what licenses that reading. Without it, a large
prediction set would be indistinguishable from a weak classifier.

\section{Case study 3: transfer to physical robots}
\label{sec:robots}

Everything so far is simulation. The framework's real claim is that a rule library
learned in simulation identifies mechanisms in a system that was \emph{not} simulated.
The same release lets us test exactly that: five \textbf{cuboid robots}, each
programmed with one of the same neighbor-selection strategies, moving in a larger
arena. Real hardware, real actuation error, real collisions -- but the generating rule
is still known, because it was programmed.

The domain shift is substantial: the arena is $1.7\times$ larger
(\SI{0.42}{\metre} vs \SI{0.25}{\metre}), kicks are $1.9\times$ slower
(\SI{0.840}{\second} vs \SI{0.434}{\second}), runs are shorter, and only ten of the
eleven rules have robot files. We take the transformer already trained on simulated
agents, \textbf{change nothing about it}, and run it on 1,961 non-overlapping robot
windows.

\paragraph{Units first.}
Positions are normalized by arena radius, so lengths are already dimensionless -- but
time is not. Speed is in arena-radii per \emph{second}, and robots kick $1.9\times$
more slowly, so a robot moving identically (the same fraction of the arena per kick)
registers about half the speed. We therefore nondimensionalize, adopting each domain's
own kick interval $\tau$ as its time unit: $\text{speed}\times\tau$,
$\text{accel}\times\tau^{2}$, $\mathrm{d}t/\tau$. This is a unit conversion, not
adaptation; it retrains nothing. It is worth $+0.085$ top-3 accuracy, and skipping it
would be as wrong as adding feet to metres.

\subsection{The transfer largely fails -- and the reason is instructive}

The same model scores $0.927$ on simulated agents and $\mathbf{0.375}$ on robots
(chance $0.10$). It retains real signal ($3.7\times$ chance) but is far from its
simulation performance. The \emph{pattern} of failure is the clue: per-rule recall is
$0.89$ for no-interaction and $0.74$ for nearest-1, and collapses to ${\sim}0$ for
every rule with $k \ge 2$, reaching exactly $0$ for all-neighbors. \textbf{The model
reads the robots as weakly interacting.}

It is right to. Comparing mean nearest-neighbor distance for the \emph{same rule}
across substrates (Table~\ref{tab:cohesion}), the discrepancy is \textbf{zero when
there is no interaction} and \textbf{grows monotonically with how cohesive the rule
ought to be}. Physical embodiment -- inertia, actuation error, sensing delay,
collision avoidance -- acts as a low-pass filter on interaction strength. A robot
programmed with all-neighbors achieves the cohesion of a simulated agent running
nearest-1.

\toprule

nearest-2      & 0.215 & 0.338 & 1.57$\times$ \\
influential-2  & 0.209 & 0.307 & 1.47$\times$ \\
all-4          & 0.182 & 0.313 & \textbf{1.71$\times$} \\
\bottomrule
\end{tabular}
\end{table}

So the classifier is not malfunctioning. It is correctly reading the \emph{behavior},
and the behavior says ``weak interaction''. It is right about the dynamics and wrong
about the rule, because \textbf{the same rule produces different dynamics on different
hardware}.

This is the paper's sharpest caution for IGSS. Behavioral-rule identification recovers
the \textbf{effective} rule -- the rule that would produce this behavior in the
substrate the library was built on -- not the \textbf{programmed} rule. A rule library
cannot be transported across embodiments without accounting for the substrate's own
dynamics.

\textbf{Transporting the calibration set across the domain shift fails silently and
catastrophically} (Table~\ref{tab:robot-conformal}). It returns small, confident sets
of 1.2--1.6 rules that contain the truth $47\%$ of the time while promising $95\%$.
Nothing in the output warns you. Exchangeability -- the one assumption conformal
prediction actually needs -- has been violated, and the guarantee is void. This is the
trap, and it is easy to fall into: the numbers look \emph{better}, not worse.

\textbf{Recalibrating on held-out robot runs restores validity} -- same weights, no
retraining, only the conformal quantile re-estimated from runs of the new system.
Coverage returns to nominal. And the restored sets contain \textbf{10 of the 11
rules}.

That is not a failure of the method. It is the method working. The set size is a
calibrated statement, and the statement it makes is: \emph{given a library built in
simulation, these robot trajectories do not identify the mechanism.} The framework
declines to guess rather than guessing confidently and wrongly.

\textbf{Conformal prediction guarantees honesty, not competence.} It cannot
manufacture information that the observation does not contain, and -- properly
calibrated -- it does not pretend to.

\section{Discussion}

\paragraph{Equifinality becomes an estimand.}
Across all three settings, the conformal set converts a qualitative caveat into a
measured quantity with an interpretable unit: the number of rules surviving at
confidence $1-\alpha$, computable per observation. The measure behaves sensibly at
very different scales -- narrowing 2,089 segregation rules to 53, eleven movement
rules to one or two, and (correctly) declining to narrow the robot rules at all. One
can now ask, quantitatively: \emph{how much data must I collect before mechanism A and
mechanism B become distinguishable?}

\paragraph{Representation matters; capacity does not.}
The case studies isolate different variables and, read together, they say something
sharper than either does alone. Collective motion varies \emph{capacity} at fixed
representation: an eleven-fold parameter increase is indistinguishable from zero.
Segregation varies \emph{representation} at fixed capacity: accuracy is nearly
identical, yet the conformal sets differ by $68\%$. The lever is not model size but
\textbf{what the model is able to represent} -- which includes, upstream of any
architectural choice, what the observation itself retains.

We would not have learned this without the aggregate control. A transformer beating a
random forest looks like a victory for agent-level modeling; the same transformer
beside a GRU reveals the gain came from the time axis, which the forest never had.

\paragraph{A cautionary note on conformal implementations.}
We found a defect in a common RAPS formulation: if the randomization term in the
non-conformity score is applied only when the true class is \emph{not} ranked first,
then for an accurate model most calibration points receive an inflated score, the
calibration quantile inflates with them, and every prediction set comes out too large.
Coverage remains \emph{valid}, so nothing in the output announces the problem. Notably,
\textbf{the severity scales with model accuracy}: our collective-motion model ($93\%$
top-1) had ${\sim}93\%$ of calibration points at rank 0 and its coverage sat at $0.97$
regardless of $\alpha$; our segregation model ($32\%$ top-1) had only ${\sim}32\%$, and
its numbers barely moved. The bug is most dangerous exactly where the model is best --
which is when one is least inclined to be suspicious. For any work measuring
equifinality \emph{by set size}, this is a silent and material error.

\paragraph{Limitations.}
The two rule-recovery case studies use simulated data with known ground truth; the
robot study uses real hardware but a programmed, not discovered, rule. The Schelling
library, though large, is a depth-3 subset of an infinite rule space. Exchangeability
holds at the level of runs rather than windows; we mitigate structurally and bootstrap
over runs. With 50 seeds, the fold-to-fold spread in the collective-motion study is
about $\pm 0.02$, which is the honest resolution of those numbers.

\paragraph{Next.}
The same release contains trajectories of \emph{real fish}. Section~\ref{sec:robots}
suggests the obvious hazard -- a library built in simulation will recover the effective
rule of the simulator, not of the animal -- and equally the obvious remedy: calibrate on
the target substrate, and let the conformal set report how much, or how little, the
observation actually determines.
